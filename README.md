# Market Basket Analysis & Association Rule Mining 🛒📊

An interactive Data Analytics and Machine Learning web application built using Python and Streamlit. This project focuses on analyzing customer purchase patterns, discovering association rules (Fp-Growth / Apriori algorithms), and generating actionable cross-selling strategies for retail business optimization.

---

## 📌 Project Overview

Market Basket Analysis helps retailers understand customer buying habits by identifying relationships between items frequently purchased together:
- **Association Rules & Patterns:** Evaluates Support, Confidence, and Lift metrics to discover product associations.
- **Actionable Cross-Selling:** Translates rule mining results into practical store layout and promotional cross-selling strategies.
